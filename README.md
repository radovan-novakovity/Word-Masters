 A Wordle-inspired guessing game built with HTML, CSS, and JavaScript. The project combines DOM manipulation and API usage to fetch the daily word from the Frontend Masters backend. Players have six attempts to guess the five-letter word of the day, receiving color-coded feedback for each guess.

# It features: 
- Fetches a new five-letter "word of the day" via an API call  
- Allows six guessing attempts per round  
- Color-coded feedback for accuracy:  
  - Gray: letter not in the word  
  - Orange: letter in the word but wrong position  
  - Green: correct letter and position  
- Logic to handle duplicate letters correctly

# Main takeaway of the project:
- Working with APIs and asynchronous JavaScript
- Managing and updating UI state dynamically  
- Implementing logical conditions to handle user input and validation  
- Using Flexbox to align game elements consistently

# Used:  
- HTML  
- CSS (Flexbox layout)  
- JavaScript (API calls, DOM manipulation, game logic)
